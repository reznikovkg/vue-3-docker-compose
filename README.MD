# 🫧 Мыльные пузыри

Игра "Мыльные пузыри" — лопай пузыри правильного цвета, зарабатывай очки и используй бомбы!

---

## 🎮 Играть прямо сейчас

👉 **[Открыть игру](https://nbubblegame.netlify.app)** 👈

> **Важно:** Сайт размещён на зарубежном хостинге (Netlify). В некоторых регионах и сетях может потребоваться **VPN** для доступа к игре. Если сайт не открывается или бесконечно загружается — включите VPN и обновите страницу.

## 🎯 Управление

| Режим | Управление | Описание |
|-------|------------|----------|
| **Клик** | Нажми на пузырь | Лопает пузыри под курсором с учётом скорости |
| **Автомат** | Автоматически каждые 0.5 сек | Стреляет по позиции курсора, показывает красные маркеры |
| **Лазер** | Проведи курсором | Пузыри лопаются по всей траектории движения |
| **Бомба** | Зажми `B` + клик | Взрывает все пузыри в радиусе (получается за 10 успешных попаданий) |

---

## ⚙️ Механики

### Множитель очков
- **Правильное попадание** → ×1.2 (макс ×5)
- **Неправильное попадание** → ×1.3 (макс ×7)
- При смене типа попадания множитель сбрасывается

### Бомбы
- Получай бомбу за каждые **10 успешных попаданий**
- Зажми `B` для активации режима бомбы
- Кликни левой кнопкой мыши, чтобы взорвать
- Большие пузыри разлетаются на 7 маленьких

### Пузыри
- **Маленькие** (radius 30) → базовый штраф ×0.6
- **Средние** (radius 45) → базовый штраф ×1.0
- **Большие** (radius 60) → базовый штраф ×1.4
